# ``GrentonModel``

The mobile interface as data, and the values CLUs report.

## Overview

``MobileInterfaceDTO`` is the interface exactly as Object Manager exports
it: CLUs, pages and widgets. ``GrentonValue`` is a value reported by a
CLU. Apps usually meet both only through `GrentonSystem`.
